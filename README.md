# ТАРЕЛЬЕ · Домашняя — онлайн-меню

Официальный проект онлайн-меню линейки «Домашняя».

- Плановый адрес: https://dom.tarelie.ru/
- Владелец: бренд «ТАРЕЛЬЕ».
- Источник сайта: `site/index.html` (полностью автономный HTML, включая фотографии).
- Публикация: REG.RU, FTP-учётная запись `u3652448_dom`, выделенная директория `/www/dom.tarelie.ru`.
- Пароли хранятся только в GitHub Actions Secrets.

Проект полностью независим от других сайтов и брендов. Запуск публикации допускается только после проверки выделенного каталога, SSL и настроек GitHub Secrets.
